## 📞 Support

### Having Issues?

1. **Resume Not Parsing**
   - Try a simpler PDF format
   - Ensure clear section headers (Skills, Experience, Education)
   - Max 10MB file size

2. **Portrait Photo Not Showing**
   - Use direct image URL (JPEG or PNG)
   - Not a Google Drive or private link
   - Suggest: Gravatar, Imgur, or profile photo CDN

3. **Text Not Displaying Correctly**
   - Check for special characters
   - Try retyping manually
   - Clear your browser cache

4. **Portfolio Not Going Live**
   - Refresh page after generation
   - Check internet connection
   - Try a different browser
